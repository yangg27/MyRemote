# MyRemote —— 属于你自己的远程控制工具

> 一个**免费、不限速、无会员**的 Windows 远程控制工具，用于替代向日葵等商业远控软件。
> 核心思路：用 **Tailscale** 把多台电脑拉进同一个虚拟局域网，远程桌面交给 Windows 原生的 **RDP**，文件传输交给 Windows 原生的 **SMB**。
> MyRemote 本身只是一个"遥控器 + 连接管理器"，不实现任何传输协议。

**当前版本：v1.7** ｜ 平台：Windows 10 / 11（专业版 / 企业版 / 教育版）｜ 技术栈：.NET 8 + WinForms

---

## 为什么做这个

| 商业远控的痛点 | MyRemote 的解法 |
|---|---|
| 免费版限速、付费才有高清 | 数据在两端宽带之间 **P2P 直连**，带宽天花板 = 你自己的宽带 |
| 画面强制走厂商服务器中转 | 画面**不经过任何第三方服务器**（Tailscale 仅协助"握手认识对方"） |
| 会员制、设备数收费 | 完全免费，设备数不限（Tailscale 免费版设备无限） |
| 装一堆后台服务、驱动 | 单文件 exe，双击即用，删除即卸载 |

## 功能一览

| 模块 | 说明 |
|---|---|
| **设备面板** | 动态设备列表（数量不限）、每 30 秒自动刷新在线状态、一键连接 |
| **远程桌面** | 内嵌 RDP 会话窗口；支持全屏(F11/ESC)、三档画质切换、断线自动重连（最多 5 次）、剪贴板互通、本机磁盘映射到对方 |
| **文件管理** | 独立窗口的双栏文件管理器（左本机 / 右远程），基于 SMB；支持上传/下载/新建/删除、进度条、取消传输；免密切入（凭据写入 Windows 凭据管理器） |
| **环境诊断** | 15 项环境自检，分 5 组（系统基础 / 网络层 / 被控端固化 / 安全强度 / 账号安全），每项给出"当前情况 + 解决指引" |
| **一键检测并修复** | 自动循环"检测 → 修复 → 复检"，最多 4 轮；需要管理员权限时自动弹 UAC 提权 |
| **一键恢复** | 每次修复前自动创建系统快照，可一键回退到修复前状态（快照含注册表 / 服务 / 休眠 / 网卡节能 / 防火墙 / 自启项） |
| **Tailscale 集成** | 一键从 Tailscale 账号导入设备（三层 fallback：LocalAPI → CLI JSON → CLI 文本解析） |
| **系统日志** | 统一日志 `MyRemote.log`（按体积滚动）+ 图形化日志查看器（实时刷新、增量渲染） |
| **界面自适应** | 自动识别系统 DPI 缩放（100%–400%），窗口与字体等比调整，小屏/高分屏均完整显示 |
| **托盘常驻** | 关闭到托盘、开机自启（写入当前用户注册表启动项） |
| **便携模式** | exe 同目录放 `.portable` 空文件，配置随 exe 走（U 盘场景） |

### 安全设计（重要）

- **3389 / 445 端口只对 Tailscale 虚拟网段（`100.64.0.0/10`）放行**，公网与物理网卡上完全"听不到"，外部扫描不到。
- 密码用 **Windows DPAPI** 加密存储（绑定当前用户），`secrets.json` 额外收紧 NTFS 权限（仅当前用户可读写）。
- SMB 凭据直接写入 **Windows 凭据管理器**（`CredWrite` P/Invoke），不以明文出现在命令行或日志中。
- RDP 启用 **NLA（网络级别认证）** 与 **AuthenticationLevel=2**（防中间人）。
- 修复前自动快照，**空/残缺快照会被拒绝执行**（防止误用默认值重写系统配置）。

## 快速开始

### 1. 获取软件

- **直接使用**：下载 [`release/MyRemote-v1.7-Delivery.zip`](release/)，解压后双击 `MyRemote.exe`（无需安装 .NET 运行时）。
- **自行编译**：见 [docs/开发与发布指南.md](docs/开发与发布指南.md)。

### 2. 部署（每台电脑做一次）

```
① 装 Tailscale（tailscale.com），所有电脑登录同一个账号
② 双击运行 MyRemote.exe → 点【一键检测并修复】→ UAC 弹窗点"是"
   （程序自动：装 Tailscale / 开远程桌面 / 关休眠 / 关网卡节能 / 配防火墙 / 开自启）
③ 点【Tailscale 登录】完成账号登录（浏览器验证，无法全自动）
④ 点【从Tailscale导入】把对端设备加入列表
⑤ 双击设备 → 远程桌面；右键设备 → 文件管理
```

详细图文流程见 **[docs/操作手册.md](docs/操作手册.md)**（面向使用者，含常见问题排查）。

## 技术栈与依赖

| 组件 | 版本/说明 |
|---|---|
| .NET | 8.0（单文件自包含发布，用户无需安装运行时） |
| UI 框架 | WinForms（`net8.0-windows`） |
| RDP 引擎 | 微软 `MsRdpClient` ActiveX 控件（COM 后期绑定，运行期探测可用 CLSID） |
| 文件传输 | Windows SMB（UNC 路径 + `CredWrite` 免密） |
| 虚拟组网 | Tailscale 官方免费版（客户端 BSD-3 开源） |
| 发布配置 | `PublishSingleFile=true` + `IncludeNativeLibrariesForSelfExtract=true` |

> 关于"为什么不自己写远程桌面协议"：RDP/SMB 由微软提供，成熟且自带多显示器、剪贴板、外设重定向、GPU 加速等能力。
> 本项目只自研 **UI 与管理逻辑**（设备/凭据/诊断/修复/文件管理器），这是最省力且最稳的路径。
> 完整论证见 [技术档案-需求与方案锁定.md](docs/技术档案-需求与方案锁定.md)。
