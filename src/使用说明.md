# MyRemote 使用说明（人话版）

> **版本**：v1.6 · 这是一个**属于你自己的**远程控制工具，用来替代向日葵。  
> 不限制速度、不收会员费、不依赖任何付费服务器。  
> 核心思路：用 **Tailscale** 把你的电脑拉进同一个虚拟局域网，远程桌面交给 Windows 自带的 RDP，文件传输交给 Windows 自带的 SMB。MyRemote 只是个"遥控器 + 连接管理器"。

---

## 本次更新（v1.5 → v1.6）都改了什么

> v1.6 是一次**全量复测 + 修 bug** 的版本：把全部源码逐文件审了一遍，修掉了 2 个会导致功能直接用不了的问题、若干安全/正确性误判，以及一批稳定性隐患。历史变更（v1.2→v1.5）见旧版说明。

| 类别      | 改动                                                              | 解决什么                                                           |
| ------- | --------------------------------------------------------------- | -------------------------------------------------------------- |
| **严重**  | **修复"第一次添加设备就崩溃"**：配置保存用了 `File.Replace`，而首次保存时目标文件还不存在         | 旧版第一次点保存会抛异常、设备存不下来；现改为不存在时直接落盘                                |
| **严重**  | **修复文件管理免密失效**：Windows 网络密码凭据必须用 **UTF-16** 存，旧版用 UTF-8，存进去的是乱码 | 旧版打开文件管理会反复弹密码框/认证失败；现已能一次写入、后续免密                              |
| **安全**  | **彻底移除 cmdkey 明文回退**：写入凭据失败时不再把密码塞进进程命令行                        | 密码不会被任务管理器/进程枚举看到，只在日志留一条失败原因                                  |
| **正确性** | **防火墙检测改为区分"已启用/已禁用"**                                          | 旧版把已禁用的默认规则也当作"已放行"，导致一键修复后仍显示未通过，怎么修都不变绿                      |
| **正确性** | **"任何地址"暴露判定修正**：只要存在一条 Any 作用域的 3389 放行规则就告警                   | 旧版若同时存在 Tailscale 规则就判"安全"，会掩盖真实暴露                             |
| **正确性** | **中文版 Windows 专业版不再被判成家庭版**：改用与语言无关的 `EditionID`                | 中文系统 `ProductName` 是"Windows 10 专业版"，旧版找不到 "Pro" 就报"家庭版不能当被控端" |
| **正确性** | **休眠检测改读注册表**，不再解析 `powercfg` 的本地化输出                            | 中文系统输出"休眠已启用"，旧版关键字匹配失败，休眠开着却显示已关闭                             |
| **正确性** | **一键恢复的默认规则组状态判断修正**                                            | 旧版几乎总判为"已启用"，恢复时可能把系统默认的"任何地址"规则重新打开，导致端口再次暴露                  |
| **稳定**  | **自动重连不再几秒内耗尽 5 次机会**：状态轮询每秒重复安排重连                              | 旧版断线后 5 秒内就把次数计满，之后再也不自动重连                                     |
| **稳定**  | **重连/切换画质时释放旧 RDP 控件与 COM 对象**                                  | 旧版反复重连会持续占用内存与句柄                                               |
| **稳定**  | **文件传输改为"临时文件 → 校验大小 → 原子替换"**                                  | 传输中断/失败/取消时不会把目标原文件覆盖成半截，也不残留损坏文件                              |
| **稳定**  | **覆盖/合并前弹窗确认**（列出生效的文件名）                                        | 避免同名文件被静默覆盖造成数据丢失                                              |
| **稳定**  | **PowerShell 脚本改用 UTF-8 BOM 写入**                                | 中文网卡名（如"以太网"）旧版会被按 ANSI 解析成乱码，导致网卡节能设置失败                       |
| **稳定**  | **网卡节能快照兼容单适配器**                                                | 旧版只有一个网卡时 JSON 结构不对，快照存了也恢复不了                                  |
| **稳定**  | **UAC 取消时提示"已取消"**；**无界面修复子进程不再弹窗**                             | 旧版取消会报"启动提权失败"；且子进程弹窗会让父进程一直卡住                                 |
| **稳定**  | **单实例互斥改为 Local→Global 逐级降级**                                   | 极少数权限受限环境旧版可能因创建全局互斥失败而打不开                                     |
| **稳定**  | 日志查看器改**增量刷新**；诊断的防火墙输出**单次复用**；Tailscale 导入改**后台加载**           | 日志窗口不再每秒重建上千行而闪烁；诊断更快；导入窗口不再"未响应"                              |
| **稳定**  | 设备配置损坏时另存 `.corrupt-时间戳` 现场；凭据文件改原子写入                           | 配置/密码不会因为一次异常写入而全部丢失，且留有排查现场                                   |

| **易用**    | **修复自动请求提权**：修复需要管理员权限时，程序自动以 UAC 拉起高权限子进程完成，无需你手动以管理员重开             | 双击打开的普通权限 MyRemote 也能顺利触发修复/恢复                      |
| **稳定**    | 「环境诊断」新增「一键修复 / 一键恢复 / 系统日志」按钮，未达标项可单独「立即修复此项」                       | 修复闭环完整、可视化                                          |

## 一、你需要准备什么

| 项目              | 说明                                          |
| --------------- | ------------------------------------------- |
| 每台电脑            | **Windows 专业版 / 企业版 / 教育版**（家庭版不能当被控端，需先升级） |
| 一个 Tailscale 账号 | 免费，官网 tailscale.com 注册，所有电脑登录**同一个**账号      |
| 每台电脑能上网         | 公司/家里都能正常出网即可，不需要公网 IP、不需要改路由器              |
| 被控账号有密码         | **不能用 PIN / 指纹 / 人脸**登录远程，必须是"账号 + 密码"      |

> **关于 ARM 设备（如骁龙笔记本 / Surface 的 ARM 版）**：我们已提供**原生 ARM64 版本** `MyRemote-arm64.exe`，可直接在 Windows 11 ARM 上原生运行，性能无损耗。x64 电脑请用 `MyRemote.exe`，ARM 电脑请用 `MyRemote-arm64.exe`。

## 二、第一次安装（每台电脑都做一遍）

### 第 1 步：装 Tailscale（关键）

1. 到 tailscale.com 下载 Windows 版，安装。
2. 登录你注册的**同一个**账号。
3. 装好后每台机器会得到一个 `100.x.x.x` 的虚拟 IP。

> 验证互通：在 A 电脑上 `Win+R` → 输入 `cmd` → 执行 `ping 100.x.x.x`（填 B 电脑的虚拟 IP）。能通说明虚拟局域网已就绪。

### 第 2 步：固化被控端（让电脑能被远程、且不失联）

1. 右键 `一键部署.ps1` → **以管理员身份运行**（脚本自己会提权，但手动右键更稳）。
2. 它自动帮你：开启远程桌面、关闭睡眠/休眠、关闭网卡节能、把 3389 和 445 防火墙**只对你自己的虚拟网段开放**。
3. **重启一次**电脑，让网卡节能设置完全生效。

### 第 3 步：放好 MyRemote

- **x64 电脑**：复制 `MyRemote.exe`；**ARM64 电脑**（骁龙/Surface ARM）：复制 `MyRemote-arm64.exe`。
- 双击即可运行，无需安装、无需装 .NET。

## 三、把电脑加进来（两种方式）

### 方式 A：从 Tailscale 一键导入（推荐，最省事）

1. 打开 MyRemote，点工具栏 **「从Tailscale导入」**。
2. 程序会列出同账号的其他机器（含在线/离线状态），**勾选**要加入的，点「导入」。
3. 用户名会自动预填本机名；若对方的 Windows 用户名不同，导入后点「编辑」改一下即可。

### 方式 B：手动添加

1. 点 **「添加设备」**，点 **「用本机信息填充」** 可把**本机**的虚拟 IP、用户名自动填入（方便你先加自己这台）。
2. 填写对方机器的：
   - **显示名**：如"家里主力机"
   - **地址/IP**：对方 Tailscale 虚拟 IP（如 `100.64.1.23`）
   - **用户名**：对方 Windows 登录用户名（不是 PIN，`whoami` 可查）
   - **RDP 端口**：默认 3389，别改
   - **共享名**：默认 `C$`（整块 C 盘），也可改为自建共享名
   - **登录密码**：对方账号密码（存在本机，别人拿不到）
3. 新买的电脑照此添加，**数量不限**。

> 设备列表默认存于 `%APPDATA%\MyRemote\devices.json`，密码用 Windows 加密存于同目录 `secrets.json`。

## 四、主界面：本机信息面板

打开 MyRemote 后，顶部有一个 **「本机信息」** 面板，会自动显示：

- 本机名、远程登录用的用户名（添加对方设备时可对照）
- 本机的 Tailscale 虚拟 IP（若显示"未检测到"，说明 Tailscale 没装或未登录同账号）
- 远程桌面被控端是否已开启（未开启会提示去跑部署脚本）

设备列表会自动**每 30 秒刷新一次在线状态**（绿色●在线 / 灰色○离线），无需手动点刷新。

## 五、环境诊断（部署前自检，强烈建议先做）

这是 v1.2 起新增的工具，目的是**在动手前一次性查清"哪里达标、哪里没达标"**，避免装到一半发现某台机器不满足要求。v1.3 起"防火墙放行 3389"能准确识别 Tailscale 网段限定规则、不再误报；v1.4 起新增"安全强度"分组，可直观看到 3389 是否仅对 Tailscale 虚拟网段开放。

### 怎么打开

主界面工具栏点 **「环境诊断」**，会弹出一个窗口，自动开始检测（约需数秒）。

### 它会检查什么（共 14 项，分 5 组）

| 分组                 | 检查项                                                                                          |
| ------------------ | -------------------------------------------------------------------------------------------- |
| **系统基础**           | ① 操作系统版本（是否专业版/企业版，家庭版不能当被控端）<br />② 远程桌面被控端是否已开启<br />③ 远程桌面服务(TermService)是否运行             |
| **网络层(Tailscale)** | ④ Tailscale 是否已安装<br />⑤ 是否已登录且本机在线<br />⑥ 是否检测到对端设备<br />⑦ P2P 直连是否建立（不限速的前提）               |
| **被控端固化**          | ⑧ 休眠是否已关闭（否则会失联）<br />⑨ 网卡节能是否已关闭（否则会断连）<br />⑩ 文件共享服务(LanmanServer)是否运行<br />⑪ 防火墙是否放行 3389 |
| **安全强度**           | ⑫ RDP(3389) 是否仅对 Tailscale 开放（防暴露）：作用域为"任何地址"则橙色告警，仅虚拟网段则绿色通过                                |
| **账号安全**           | ⑬ 远程登录是否依赖 PIN/指纹（远程不能用 PIN 登录）<br />⑭ 是否已配置开机自启（推荐）                                         |

### 结果怎么看

- 顶部一行统计：**通过 / 需关注 / 未满足 / 提示 / 未知** 各几项。
- 列表里每行左侧有彩色状态字：**✔ 通过**（绿）、**⚠ 需关注**（橙）、**✘ 未满足**（红）、**ℹ 提示**（蓝）、**? 未知**（灰）。
- 窗口打开后**默认自动选中第一个红/橙项**，下方立即显示它的"当前情况"和"解决指引"。

### 关键：点一下不符合的项，看怎么办

**点击列表里的任意一行**，窗口下方就会显示这一项的：

- 【当前情况】——实际检测到的内容（例如"fDenyTSConnections=1（被禁用）"）
- 【解决指引】——**一步一步的操作方法**（例如"右键以管理员运行一键部署.ps1，或手动：设置→系统→远程桌面→开启"）

> 也就是说：**红的项点进去就有现成的修复步骤**，照着做即可，不需要自己猜。修完点工具栏 **「重新检测」** 复查是否变绿。

### 建议流程

1. 每台机器先跑一次「环境诊断」。
2. 把所有 **✘ 未满足** 项按指引处理掉（多为跑一次部署脚本、或装/登录 Tailscale）。
3. 把 **⚠ 需关注** 项尽量处理（休眠、网卡节能、PIN 等）。
4. 全部变绿或只剩"提示"后，再开始正式连接使用。

### 一键修复 / 一键恢复（v1.5 新增）

诊断窗体工具栏上有三个新按钮，构成一个完整的"检测 → 修复 → 回退"闭环：

- **「一键修复」**：把当前所有**红（未满足）/ 橙（需关注）且可自动修复**的项一次性修好（开 RDP、启服务、关休眠、关网卡节能、按 Tailscale 网段配防火墙、开开机自启）。
- **「立即修复此项」**（点中某行后下方出现）：只修你选中的那一项。
- **「一键恢复」**：把系统**回退到最近一次修复前的状态**（每次修复前都会自动留快照）。

> **重要前提与提示**：
>
> 1. 修复需要管理员权限。若你是以普通身份双击打开的 MyRemote，点「一键修复/恢复」时程序会**自动弹出 UAC 请求**（类似"是否允许此应用对你的设备进行更改"），点「是」即可；若你点「否」，修复不会执行，并会提示你可用"右键 → 以管理员身份运行"的方式打开。
> 2. **修复前会自动创建快照**并保存在配置目录的 `Rollback\` 下（文件名带时间戳 + `last.json`）。只有执行过修复，才会有可恢复的快照。
> 3. 凡涉及防火墙的修复，效果与「一键部署.ps1」一致：禁用系统默认"远程桌面/文件共享"规则组，仅以 Tailscale 网段 `100.64.0.0/10` 放行 3389/445。
> 4. 少数项（如"操作系统版本=家庭版""Tailscale 未安装""PIN/指纹依赖"）无法自动修复，这些项在窗体里不会开放修复按钮，仍需你按指引手动处理。

### 系统日志与错误排查（v1.5 新增）

- 主界面与诊断窗体都有 **「系统日志」** 按钮，点开是一个实时刷新的日志查看器（时间 / 级别 / 组件 / 消息），可"打开日志文件"或直接复制。
- 日志文件位于配置目录 **`MyRemote.log`**（按体积自动滚动，不会无限变大）。
- 程序运行期间的**所有操作、修复过程、错误信息**都会写进去，是故障排查与后续升级回溯的主要依据。
- 关键运行错误（如文件传输失败、RDP 初始化失败）会**弹窗提示**并同时写日志，不再静默失败。

## 六、远程控制（远程桌面）

1. 设备列表选中一台，点 **「远程桌面」**（或双击）。
2. 稍等片刻，窗口里就是对方桌面：
   - **全屏**：点工具栏「全屏 (F11)」或按 `F11` 切换；退出除再按一次外，还可按 `ESC`，或点工具栏的「退出全屏」。（全屏时工具栏保持可见，避免卡死）
   - **画质**：下拉可选「自动 / 高速(省带宽) / 高清(1920x1080)」，切换后自动重连——卡顿时选"高速"立刻变流畅
   - **断线自动重连**：点工具栏「自动重连:开」开启。无人值守时网络闪断会自动恢复（最多重试 5 次），点「断开」或关窗口即停止
   - 本机磁盘会映射到对方"此电脑"里，可直接拖文件；剪贴板互通
3. 点 **「断开」** 或关窗口退出；改画质点 **「重连」**。
4. 账号支持 `域\用户` 形式（域账号 / 微软账户均可）；远程登录仍**只能用密码**，不能用 PIN。

> 连上后**对方那块屏幕会被锁定**（Windows 特性，不是 bug）。你不在对方面前操作，无影响。  
> 若长时间停在"正在连接…"或出现红色"连接较慢或失败"提示，多半是地址填错 / 对端未开机 / 凭据是 PIN。先跑一次「环境诊断」按指引排查。

## 七、文件管理（独立窗口）

1. 选中设备，点 **「文件管理」**。
2. 左边是本机，右边是对方（通过 `\\虚拟IP\C$` 访问），**独立于远程桌面**，不连桌面也能传。
3. 操作：
   - **双击文件夹**进入；点 **「↑上级」** 返回
   - 选中 → **「→ 上传到远程」** / **「← 下载到本地」**
   - **「+本地文件夹」/「+远程文件夹」** 新建目录
   - **「删除所选」**（谨慎，不可恢复）
   - 底部进度条显示传输进度；传输中点 **「取消传输」** 可中止

## 八、常驻、自启与便携

- **关闭到托盘**：点窗口右上角关闭按钮，程序不会退出，而是**最小化到右下角托盘**，保持常驻；双击托盘图标恢复，右键托盘可「退出」。
- **开机自启**：右键托盘图标 → 勾选 **「开机自启」**（写入当前用户的注册表启动项，不影响其它用户）。
- **便携模式**：如果你想把 MyRemote 连同配置一起带走（U 盘 / 多机拷贝），在 `MyRemote.exe` **同目录**放一个名为 `.portable` 的空文件（或该目录已存在 `devices.json`），程序就会把配置存到 exe 旁边而非 `%APPDATA%`。
  > 注意：密码用 Windows DPAPI 加密，绑定当前用户。换到另一台机器/另一用户时，加密的密码无法解密，需重新输入一次。

## 九、安全说明（请务必读）

- **3389 和 445 只对 Tailscale 虚拟网段开放**：v1.4 的部署脚本会**主动禁用系统默认的"远程桌面"和"文件和打印机共享"防火墙规则组**（它们默认作用域是"任何地址"），仅保留一条明确限定 `100.64.0.0/10` 的自定义规则。因此这两个端口在公网和物理网卡上完全"听不到"，外部扫描不到，不怕暴力破解和勒索病毒。可用主界面的「环境诊断」→"安全强度"项直观核验。
- 密码存在**你本机**，用 Windows 登录会话加密（DPAPI），换台电脑读不出来；v1.4 起 `secrets.json` 还会收紧 NTFS 权限，**仅当前用户可读写**。
- 文件管理用到的远程登录凭据，由程序**直接写入 Windows 凭据管理器**（与系统"凭据管理器"里看到的网络密码一致），不会以明文出现在任何命令行或日志中；换台电脑需重新输入一次。
- 画面数据在双方直连时**完全不经过 Tailscale 服务器**；只有"握手认识对方"走它。即使走中继，内容端到端加密，官方看不了。
- **不要把 MyRemote / 密码 / 配置文件发给别人**，这是你私人的工具。

## 十、常见问题

| 现象                   | 排查                                                                                                       |
| -------------------- | -------------------------------------------------------------------------------------------------------- |
| 环境诊断里"Tailscale 未安装" | 到 tailscale.com 下载安装并登录同账号；装完点「重新检测」                                                                     |
| 诊断里"未登录/未在线"         | 点任务栏 Tailscale 图标确认已登录、图标为绿色                                                                             |
| 诊断里"P2P 直连"是橙色的      | 公司严限 UDP 出网时会走中继变慢；优先改用公司官方 VPN，或换 ZeroTier                                                              |
| 诊断里"操作系统版本"是红        | 家庭版需升级专业版才能当被控端                                                                                          |
| 诊断里"休眠/网卡节能"是橙       | 按指引手动关闭（或重跑一键部署.ps1 后重启）                                                                                 |
| 诊断里"PIN/指纹"是橙        | 远程只能用密码登录，去 设置→账户→登录选项 给账户加密码                                                                            |
| 添加设备后状态一直"离线"        | 确认对方 Tailscale 已登录同账号、已开机；`ping 对方虚拟IP` 试一下                                                              |
| 「从Tailscale导入」提示无对端  | 确认 tailscale 已装且登录、其它设备已上线；`tailscale status` 自查                                                         |
| 远程桌面连不上，提示凭据         | 确认用**密码**不是 PIN；用户名正确（含机器名前缀按需）                                                                          |
| 远程桌面提示"不支持"或黑屏       | 被控端需专业版以上，且 `一键部署.ps1` 已跑过                                                                               |
| 文件管理打不开对方盘           | 确认 `一键部署.ps1` 已跑（开 SMB）；首次会让你输一次密码并记住                                                                    |
| 公司网络连不上/很慢           | 公司严限 UDP 出网时 Tailscale 走中继变慢；优先改用公司官方 VPN                                                                |
| 连上后卡顿                | 一般是两家宽带上行不够；把远程桌面画质切到"高速(省带宽)"                                                                           |
| 全屏后不知道怎么退出           | 再按 `F11`、按 `ESC`、或点工具栏「退出全屏」任一即可（全屏时工具栏始终可见）                                                             |
| 网络闪断后桌面没了            | 开「自动重连:开」会自动恢复；未开则手动点「重连」                                                                                |
| 文件管理首次要输密码           | 首次打开文件管理会按设备地址把凭据存入 Windows 凭据管理器并记住，之后免输（v1.6 修正了密码编码，旧版可能反复索要密码）；若提示拒绝访问，确认该账号在被控端有密码且密码正确             |
| 启用自动重连后仍频繁断          | 多为网络不稳或 Tailscale 走中继；优先改用公司官方 VPN，或换 ZeroTier                                                           |
| ARM 笔记本上跑哪个          | x64 电脑用 `MyRemote.exe`；ARM64 电脑（骁龙/Surface ARM）用 `MyRemote-arm64.exe` 原生版                                |
| 诊断"安全强度"是橙色          | 说明 3389 对"任何地址"开放，有暴露风险；重新以管理员运行「一键部署.ps1」即可收紧为仅 Tailscale 网段                                            |
| 想看程序到底做了什么 / 报错详情    | 主界面或诊断窗体点 **「系统日志」** 实时查看；或打开配置目录下的 `MyRemote.log`                                                       |
| 一键修复后想反悔 / 担心改坏      | 诊断窗体点 **「一键恢复」** 即可回退到修复前的系统快照（每次修复前自动创建，存于 `Rollback\`）                                                 |
| 点一键修复提示"未授予管理员权限"    | 普通权限打开时 UAC 被你拒绝了；右键 MyRemote → **以管理员身份运行** 后再点修复即可                                                     |
| 一键修复后重新检测仍是红/橙       | ①先确认用的是 **v1.6**（v1.5 及以前会把"已禁用"的防火墙规则误判为已放行）②"家庭版 / Tailscale 未装 / PIN 依赖"本身不可自动修 ③"对端设备 / P2P"要看对方是否在线 |

## 十一、卸载

- 删除 `MyRemote.exe` 即可，无残留。
- 彻底清除配置：删掉 `%APPDATA%\MyRemote` 文件夹（或 exe 旁的 `devices.json`/`secrets.json`）。
- 移除 Tailscale：系统设置里正常卸载。
