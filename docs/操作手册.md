## 一、准备工作

| 项目 | 要求 |
|---|---|
| 操作系统 | **Windows 专业版 / 企业版 / 教育版**（家庭版不能作为被控端，这是微软的 SKU 级限制，无法绕过） |
| Tailscale 账号 | 免费注册（tailscale.com），**所有电脑登录同一个账号** |
| 网络 | 各台电脑都能正常出网即可；**不需要公网 IP、不需要改路由器** |
| 被控账号 | 必须用**密码**登录（PIN / 指纹 / 人脸**不能**用于远程认证） |

## 二、部署（每台电脑做一次）

### 第 1 步：放好程序

从交付包 `MyRemote-v1.7-Delivery.zip` 解压出整个文件夹（**保持目录结构，`packages` 文件夹别丢**）：

```
MyRemote.exe                       主程序（双击运行，无需安装 .NET）
packages\
  tailscale-setup-1.104.1.exe      内置 Tailscale 安装包（程序会自动使用）
使用说明.txt
```

### 第 2 步：一键检测并修复（推荐，最省事）

1. 双击 `MyRemote.exe`
2. 点左上角 **【一键检测并修复】**
3. 程序自动循环"检测 → 修复 → 复检"，期间弹出 UAC 授权，点 **【是】**

自动完成的事情：

- ✅ 安装 Tailscale（用内置安装包静默安装）
- ✅ 注册/修复 RDP 客户端控件
- ✅ 开启远程桌面被控端 + 启动 TermService
- ✅ 启动文件共享服务（LanmanServer）
- ✅ 关闭休眠、关闭网卡节能（防止远程连接中途掉线）
- ✅ 配置防火墙：仅对 Tailscale 网段（`100.64.0.0/10`）放行 3389/445

> 修复前会自动创建系统快照，随时可点【一键恢复】回退。

### 第 3 步：登录 Tailscale

点主界面 **【Tailscale 登录】** 按钮，在弹出的界面里点 `Log in`，用浏览器完成账号验证（这一步无法全自动）。两台电脑登同一个账号。

### 第 4 步：导入设备

在一台电脑上点 **【从Tailscale导入】**，勾选另一台电脑，点【导入】。

> 也可以手动点【添加设备】，填对方的虚拟 IP（`100.x.x.x`）+ 用户名 + 密码。

### 第 5 步：连接

- **双击设备** → 建立远程桌面连接
- **右键设备 → 文件管理** → 通过 SMB 传输文件

## 三、日常使用

### 3.1 远程桌面

| 操作 | 说明 |
|---|---|
| 双击设备 / 选中点【远程桌面】 | 建立连接 |
| **全屏** | 工具栏点【全屏】或按 `F11`；退出按 `F11` / `ESC` / 点【退出全屏】（全屏时工具栏保持可见，避免卡死） |
| **画质切换** | 下拉可选「自动 / 高速(省带宽) / 高清(1920x1080)」，切换后自动重连。卡顿时选"高速"立刻变流畅 |
| **自动重连** | 点【自动重连:开】。网络闪断后自动恢复（最多 5 次）；点【断开】或关窗口即停止 |
| **剪贴板** | 自动互通，直接复制粘贴 |
| **磁盘映射** | 本机磁盘会映射到对方"此电脑"里，可直接拖文件 |

> 连上后**对方那块屏幕会被锁定**（Windows 特性，不是 bug）。无人值守场景无影响。

### 3.2 文件管理

选中设备 → 点【文件管理】，打开独立窗口（**不连桌面也能传**）：

| 按钮 | 功能 |
|---|---|
| 双击文件夹 | 进入目录 |
| 【↑上级】 | 返回上级 |
| 【→ 上传到远程】/【← 下载到本地】 | 传输选中项 |
| 【+本地文件夹】/【+远程文件夹】 | 新建目录 |
| 【删除所选】 | 删除（谨慎，不可恢复） |
| 【取消传输】 | 中止当前传输 |

传输机制：临时文件 → 校验大小 → 原子替换。中断/失败/取消时**不会**把目标文件搞成半截。覆盖同名文件前会弹窗确认。

### 3.3 本机信息面板

主界面顶部的【本机信息】面板自动显示：本机名、远程登录用户名、本机 Tailscale 虚拟 IP、远程桌面被控端是否已开启。

设备列表**每 30 秒自动刷新在线状态**（绿色●在线 / 灰色○离线）。

## 四、环境诊断与一键修复

### 4.1 打开诊断

主界面工具栏点 **【环境诊断】**，自动开始检测（约数秒）。

### 4.2 检查项（15 项，分 5 组）

| 分组 | 检查项 |
|---|---|
| **系统基础** | ① 操作系统版本（家庭版不能当被控端）② 远程桌面被控端是否开启 ③ TermService 是否运行 |
| **网络层** | ④ Tailscale 是否安装 ⑤ 是否登录且在线 ⑥ 是否检测到对端设备 ⑦ P2P 直连是否建立（不限速的前提） |
| **被控端固化** | ⑧ 休眠是否关闭 ⑨ 网卡节能是否关闭 ⑩ LanmanServer 是否运行 ⑪ 防火墙是否放行 3389 |
| **安全强度** | ⑫ RDP(3389) 是否**仅**对 Tailscale 开放 |
| **账号安全** | ⑬ 是否依赖 PIN/指纹 ⑭ 开机自启是否配置 ⑮ 界面自适应（显示当前缩放比例与屏幕尺寸） |

### 4.3 结果怎么看

- 顶部统计：**通过 / 需关注 / 未满足 / 提示 / 未知**
- 状态色：**✔ 通过**（绿）、**⚠ 需关注**（橙）、**✘ 未满足**（红）、**ℹ 提示**（蓝）、**? 未知**（灰）
- **点击任意一行**，下方显示该行的【当前情况】与【解决指引】——红的项点进去就有现成的修复步骤

### 4.4 一键修复 / 一键恢复

| 按钮 | 作用 |
|---|---|
| 【一键检测并修复】 | 自动循环"检测 → 修复 → 复检"（最多 4 轮），直到无待修复项 |
| 【立即修复此项】 | 只修选中的那一项 |
| 【一键恢复】 | 回退到最近一次修复前的系统状态 |

**重要前提**：

1. 修复需要管理员权限。普通身份双击打开的 MyRemote 点修复时会**自动弹 UAC**，点【是】即可；点【否】会提示改用"右键 → 以管理员身份运行"。
2. 修复前自动创建快照，存于配置目录 `Rollback\`。**只有执行过修复才有可恢复的快照。**
3. 少数项无法自动修复（家庭版、Tailscale 未装、PIN 依赖），需按指引手动处理。

### 4.5 系统日志

主界面与诊断窗体都有【系统日志】按钮，打开实时刷新的日志查看器（时间/级别/组件/消息），可"打开日志文件"或复制。

日志文件：`%APPDATA%\MyRemote\MyRemote.log`（按体积自动滚动）。

关键错误（文件传输失败、RDP 初始化失败）会**弹窗提示**并写日志，不会静默失败。

## 五、界面自适应说明

程序自动识别系统缩放比例（100% / 125% / 150% / 175% / 200% 等）并相应调整窗口与文字大小，在笔记本小屏、高分屏上都能完整显示，不会出现"文字被截断""按钮跑到屏幕外"。

**已实测验证**：100% ～ 400% 缩放 × 1280×720 至 4K 各种屏幕组合，逐项检查无溢出。

若仍觉得字太小或太大，可手动指定（临时排障用）：

```cmd
set MYREMOTE_UI_SCALE=1.25
（数值即缩放比例，如 1.0 / 1.25 / 1.5，范围 0.5～4）
```

在同一 cmd 窗口里输入 `MyRemote.exe` 的完整路径回车启动。

在【环境诊断】右侧会显示当前生效的缩放比例，便于确认。

## 六、便携模式与托盘

| 功能 | 用法 |
|---|---|
| **关闭到托盘** | 点窗口关闭按钮不会退出，而是最小化到右下角托盘；双击托盘图标恢复，右键托盘可【退出】 |
| **开机自启** | 右键托盘图标 → 勾选【开机自启】（写入当前用户的注册表启动项） |
| **便携模式** | 在 `MyRemote.exe` **同目录**放一个名为 `.portable` 的空文件（或该目录已存在 `devices.json`），配置就会存到 exe 旁边而非 `%APPDATA%` |

> 便携模式注意：密码用 Windows DPAPI 加密，**绑定当前用户**。换机器/换用户后加密的密码无法解密，需重新输入一次。

## 七、常见问题速查

| 现象 | 排查方向 |
|---|---|
| 诊断里"Tailscale 未安装" | 到 tailscale.com 下载安装并登录同账号；装完点【重新检测】 |
| 诊断里"未登录/未在线" | 点任务栏 Tailscale 图标确认已登录、图标为绿色 |
| 诊断里"P2P 直连"橙色 | 公司严限 UDP 出网时会走中继变慢；优先改用公司官方 VPN，或换 ZeroTier |
| 诊断里"操作系统版本"红色 | 家庭版需升级专业版才能当被控端 |
| 诊断里"休眠/网卡节能"橙色 | 按指引手动关闭，或重跑一键修复后重启 |
| 诊断里"PIN/指纹"橙色 | 远程只能用密码登录，去 设置→账户→登录选项 给账户加密码 |
| 诊断"安全强度"橙色 | 3389 对"任何地址"开放有暴露风险；重新跑一次一键修复即可收紧 |
| 添加设备后一直"离线" | 确认对方 Tailscale 已登录同账号、已开机；`ping 对方虚拟IP` 试一下 |
| 「从Tailscale导入」无对端 | 确认 tailscale 已装且登录、其它设备已上线；`tailscale status` 自查 |
| 远程桌面连不上，提示凭据 | 确认用**密码**不是 PIN；用户名正确 |
| 远程桌面提示"不支持"或黑屏 | 被控端需专业版以上，且已完成一键修复 |
| 文件管理打不开对方盘 | 确认已完成一键修复（开 SMB）；首次会让你输一次密码并记住 |
| 公司网络连不上/很慢 | 多半是 UDP 受限走中继；优先改用公司官方 VPN |
| 连上后卡顿 | 一般是宽带上行不够；把画质切到"高速(省带宽)" |
| 全屏后不知道怎么退出 | 按 `F11` / `ESC` / 点【退出全屏】任一即可 |
| 网络闪断后桌面没了 | 开【自动重连:开】会自动恢复；未开则手动点【重连】 |
| 一键修复后想反悔 | 诊断窗体点【一键恢复】回退到修复前快照 |
| 点一键修复提示"未授予管理员权限" | UAC 被你拒绝了；右键 MyRemote → **以管理员身份运行** 后再点修复 |
| 想程序到底做了什么 / 报错详情 | 点【系统日志】实时查看；或打开 `%APPDATA%\MyRemote\MyRemote.log` |
| 诊断"界面自适应"项想反馈问题 | 该项显示当前缩放比例与屏幕尺寸，截图反馈即可快速定位 |

## 八、数据存放位置与卸载

### 配置文件位置

| 模式 | 位置 |
|---|---|
| 默认 | `%APPDATA%\MyRemote\` |
| 便携模式 | exe 同目录 |

目录内容：

| 文件 | 内容 |
|---|---|
| `devices.json` | 设备列表（明文 JSON） |
| `secrets.json` | 密码（DPAPI 加密，ACL 收紧至仅当前用户） |
| `MyRemote.log` | 运行日志 |
| `Rollback\` | 修复前快照（`snapshot_*.json` + `last.json`） |
| `Rollback\_invalid\` | 被隔离的无效快照（历史遗留空文件） |
| `crash.log` | 崩溃日志（出现异常时生成） |

### 卸载

- 删除 `MyRemote.exe` 即可，无残留。
- 彻底清除配置：删掉 `%APPDATA%\MyRemote` 文件夹。
- 移除 Tailscale：系统设置里正常卸载。
